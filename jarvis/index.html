Делай с компьютера. Джарвис ставится на компьютер, и промпты удобнее вставлять там. Скинь ссылку себе в Telegram или на почту и открой её на компьютере.

Шаг 1

Открой Claude Code или Codex

Джарвиса ставит и настраивает ИИ-агент на твоём компьютере. Выбери агента, которым пользуешься:

  1. Открой приложение Claude. Если его нет — скачай для Windows или macOS с claude.ai/download и войди.
  2. Перейди на вкладку Code и выбери папку «Документы».

Режим Code есть в платной подписке Claude. Привык к терминалу — открой папку и набери claude, это то же самое.

  1. Открой приложение Codex или терминал. Если Codex нет — поставь по официальной инструкции и войди через аккаунт ChatGPT.
  2. Выбери папку «Документы». В терминале — так:
Терминал · Windows и macOS
cd ~/Documents
codex

Лимиты Codex зависят от твоего тарифа ChatGPT. Сам Джарвис работает на Claude Code — промпт из шага 2 проверит, что он установлен и ты в нём вошёл.

Промпты одинаковые для Windows и Mac: агент сам определит систему. Когда он спрашивает разрешение на действие, читай, что он собирается сделать, и разрешай.

Шаг 2

Вставь промпт — агент всё установит

Агент сам поставит недостающие программы, скачает проект с GitHub, настроит голос и сделает ярлык «Джарвис» на рабочем столе.

Промпт · Установка
Установи мне голосового ассистента JARVIS из открытого проекта https://github.com/adewaskar/jarvis и доведи его до рабочего состояния. Я новичок: всё делай сам, а меня спрашивай, только когда без меня никак.

1. Определи мою систему (Windows или macOS). Проверь, что есть Git, Node.js версии 20 или новее и Claude Code, в котором я вошёл в аккаунт: Джарвис работает только на Claude Code. Чего нет — поставь сам официальным способом для моей системы, а войти в Claude Code помоги мне.
2. Склонируй репозиторий в папку jarvis в моей папке «Документы», прочитай README и установи всё по нему: npm install, потом npm run setup. Если setup на что-то жалуется — исправь.
3. Голос. Спроси, есть ли у меня API-ключ ElevenLabs. Если нет — коротко объясни, где его взять (elevenlabs.io → API Keys → Create API Key, доступы Text to Speech и Speech to Text), и подожди. Когда пришлю — сохрани его в постоянную переменную окружения ELEVENLABS_API_KEY для моего пользователя и больше нигде его не показывай. Если я отвечу «без голоса» — пропусти этот пункт.
4. Сделай на рабочем столе ярлык «Джарвис» (на Windows — файл .bat, на macOS — .command): он запускает npm start в папке проекта в отдельном окне, а через несколько секунд открывает http://localhost:5173 в Chrome или Edge.
5. Запусти Джарвиса этим ярлыком, проверь, что всё поднялось, и скажи, что нажать в браузере.

Не включай режим --writes и не меняй настройки безопасности проекта (bridge/policy.mjs). Перед каждым шагом коротко пиши, что делаешь.
Про ключ ElevenLabs

С ключом у Джарвиса живой голос, и он понимает русскую речь. Без ключа он понимает только английский. Для пробы хватит бесплатного тарифа ElevenLabs.

Ключ — как пароль. Отправляй его только агенту на своём компьютере, не показывай на видео и не пересылай в другие чаты.

Шаг 3

Скажи «Hey Jarvis»

Агент откроет Джарвиса в браузере. Тут три нажатия, их браузер даст сделать только тебе:

  1. Нажми INITIALISE.
  2. Разреши доступ к микрофону.
  3. Скажи «Hey Jarvis» или зажми Пробел и говори.

В следующий раз запускай Джарвиса ярлыком на рабочем столе.

Не закрывай окно консоли

Ярлык открывает чёрное окно: в нём работает «мозг» Джарвиса. Закроешь его — Джарвис замолчит.

Шаг 4

Подключи почту, календарь, документы, CRM

Вставь в тот же чат с агентом. В квадратных скобках впиши свою CRM или другой сервис, а если не нужно — удали эту строку.

Промпт · Сервисы
Подключи к моему Джарвису почту, календарь и документы.
Ещё подключи: [название CRM или другого сервиса].

1. Gmail, Google Calendar и Google Drive подключаются как коннекторы в настройках claude.ai. Скажи, что мне там нажать, и подожди, пока я подключу.
2. Потом поправь ярлык «Джарвис» на рабочем столе, чтобы он запускался с переменной JARVIS_ACCOUNT_CONNECTORS=1, и перезапусти Джарвиса.
3. Для других сервисов найди официальный MCP-сервер или способ подключиться через API. Объясни простыми словами, что Джарвис сможет читать и что менять, и после моего «да» подключи его к Claude Code. Если нужен ключ — скажи, где его взять, и сохрани так же, как ключ ElevenLabs.

Режим --writes не включай без моего отдельного разрешения.

Войти в аккаунт Google за тебя агент не может: это делаешь сам, он подскажет, куда нажать. Потом спроси Джарвиса: «Какие у меня встречи завтра?» Если с первого раза не нашёл — спроси ещё раз: сервисы подключаются со второй реплики.

Чтобы он не только читал, но и действовал

По умолчанию Джарвис только смотрит: найдёт письмо, но не отправит. Чтобы отправлял и удалял, попроси агента: «Сделай второй ярлык Джарвиса с режимом --writes». В этом режиме Джарвис может всё, что может твой пользователь на компьютере. Фраза «почисти загрузки» здесь значит настоящее удаление.

Честно о главном

  • «Бесплатно» — про код. Думает Джарвис на твоей подписке Claude и тратит те же лимиты, что обычная работа в Claude Code. Даже если ставил его через Codex, нужен Claude Code с подпиской.
  • Без ElevenLabs — только английский. С ключом он понимает русскую речь и отвечает голосом ElevenLabs.
  • Нужен обычный Chrome или Edge. Встроенные окна приложений блокируют микрофон: страница выглядит живой, но ничего не слышит.
  • Это чужой открытый код. Проект открытый, лицензия MIT, около тысячи звёзд на GitHub. Ставь только по ссылке из этого гайда.
  • Только для тебя. Джарвис доступен только с этого компьютера. Не открывай его в сеть.

Если что-то не работает

Любая ошибка

Напиши в тот же чат с агентом, что видишь на экране, или вставь скриншот. Он сам разберётся и починит.

Джарвис не слышит или молчит

Нажми D — откроется диагностика: там видно, слышит ли он тебя и выдаёт ли звук. T — проверка звука. Проверь, что это Chrome или Edge в обычном окне и микрофон разрешён.

Говорю по-русски, а он не понимает

Значит, ключ ElevenLabs не подхватился. Скажи агенту: «Джарвис не видит ключ ElevenLabs, проверь и почини».
